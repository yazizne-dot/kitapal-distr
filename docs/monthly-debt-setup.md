# Айлық қарыз есебін қосу

1. Supabase → SQL Editor ішінде `supabase/migrations/20261020100000_monthly_debt_reports.sql` файлын толық орындаңыз. Алдыңғы `20260924110000_monthly_opening_debt.sql` миграциясы орындалған болуы керек.
2. Егер pg_cron кеңейтімін қосу қатесі шықса, Database → Extensions ішінен pg_cron қосып, миграцияны қайта орындаңыз. Миграция транзакциямен орындалады.
3. Сайтты жаңартып, «Қарыз және лимит жүйесі» → «Ай бойынша» сүзгісін таңдаңыз.

Бастапқы қарызды қолмен өзгерту үшін бұдан кейін `supabase/migrations/20261020110000_edit_month_opening_debt.sql` миграциясын орындаңыз. «Ай басындағы қарыз» жанындағы «✎ Өзгерту» батырмасы ағымдағы ай үшін админ мен рұқсаты бар менеджерге көрсетіледі. Түзету нақты қарызға сол айырманы қосады; өткен айдың жабылған қарызы сақталады. Өзгерткен қолданушы мен уақыт базада тіркеледі. Біреу қатар өзгертіп үлгерсе, бетті жаңартып, қайта енгізу қажет.

Ай басындағы қарыз бұрыннан бар `monthly_opening_debts` кестесінде әр дистрибьютор/ай үшін бір жазбамен сақталады. Күнделікті Алматы уақытымен 00:00-де орындалатын тапсырма жаңа айды ашады. Сайттағы есепті сұрау да өткізіліп алған айларды толықтырады. Жабылған айдың нақты қарызы келесі айдың сақталған бастапқы қарызына тең; төлем жиыны да жабылғанда сақталады. Ағымдағы айға жаңа тапсырыс пен төлем қосылған сайын нақты қарыз жаңарады. Қарызды әкімші қолмен түзетсе, ол да ағымдағы нақты қарызға кіреді.

Бұрын сақталмаған айларға жалған тарих жасалмайды. Өткен айлардағы кредит лимитінің бұрынғы өзгерістері тіркелмегендіктен, алғашқы көшіру кезінде қолданыстағы лимит алынады; кейінгі айлар үшін лимит сақталады. Өткен күнмен төлем қосу немесе бұрынғы тапсырысты өзгерту жабылған қалдықты қайта жазбайды; өзгеріс ағымдағы қарызда ескеріледі. Ескі төлемді жою қажет болса, төлемдер тарихы бастапқы жазбаларды көрсететінін ескеріңіз: жабылған айдың сақталған жиыны өзгермейді.

Тексеру:

```sh
node scripts/check-monthly-debts.mjs
npm run build -- --configuration development
```

`supabase/tests/monthly_debt_rollover.sql` сценарийін миграциялар қолданылған **тест базасында** орындаңыз. Ол бастапқы қарызды көшіруді, төлем жиынын, қайталап орындауды және жоспарлаушының барын тексереді; тест деректері rollback арқылы қайтарылады.
