# Kitapal Distributor Portal

Angular-прототип дистрибьютор порталы по ТЗ: 9 қала, 6 айлық мақсаттар, жеңілдіктер, прайс-лист, тапсырыстар, қарыз лимиті және admin/manager/distributor рөлдері.

## Как запустить

1. Установите Node.js.
2. В папке проекта выполните:

```bash
npm install
npm start
```

3. Откройте сайт в браузере по адресу:

```text
http://localhost:4200
```

## Что есть на сайте

- Login экраны для Admin, Manager және Distributor;
- dark sidebar + light content;
- мақсат прогресі және жеңілдік жүйесі;
- дистрибьюторлар карточкалары;
- «Менің бағам» прайс-листі;
- тапсырыс беру және статус бақылау;
- қарыз және credit limit ескертуі;
- хабарламалар, Excel импорт және Supabase RLS қауіпсіздік экрандары.
